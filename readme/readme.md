# Student Hub Portal

## 📚 About the Project

Student Hub is a centralized web portal designed to provide college students with easy access to academic information and important college resources in one place.

The portal provides a clean, modern, and responsive interface where students can access their profile, attendance, timetable, academic performance, announcements, study resources, events, and notifications.

## 🎯 Objectives

* Create a centralized platform for students.
* Provide easy access to academic information.
* Organize college announcements and resources.
* Improve the overall student experience.
* Create a responsive and user-friendly web interface.

## 🚀 How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Log in using the available demo credentials.
5. Navigate through the Student Hub portal.

For development, the project can also be opened using VS Code with the Live Server extension.
